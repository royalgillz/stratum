# Kernel specs

Prefix `KERN`. Design: `kernel-design.md`. The problems served are in brackets.

- [x] **KERN-001** [all]: On each step, the kernel shall call every adapter exactly once, in ascending `id` order whatever the order supplied, with the fixed step `dt` in world seconds, and then set `world.t` to `t0 + n × dt` after `n` steps; an empty adapter list shall still advance `t`.
- [x] **KERN-002** [all]: When a kernel is created, it shall throw a RangeError for duplicate adapter ids, for a `dt` that is not finite and above 0, and for any adapter whose `writes` include `t`, `seed` or `clock`.
- [x] **KERN-003** [all]: The kernel shall create one stream per adapter as `rng(world.seed, adapter.id)` when the kernel is created and pass that same stream on every step, so that adding or removing another adapter leaves an adapter's draws unchanged.
- [x] **KERN-004** [all]: If an adapter assigns to, deletes from or mutates (at any depth) a World key not in its `writes` while checked mode is on, or if an adapter's `step` or `metric` throws, then the kernel shall throw a `KernelError` naming the adapter, the key (for a write) and the world time, carrying a thrown error as `cause`, and every later call on that kernel (`step`, `run`, `advance`, `setClock`, `metrics`) shall throw that same error.
- [x] **KERN-005** [all]: When `metrics()` is called, the kernel shall return each adapter's `metric(world)` keyed by id, computed on a read-only view, and shall throw a `KernelError` if a metric has a label other than LIVE, REPLAY or SIMULATED or a non-finite value.
- [x] **KERN-006** [all]: Given the same seed, adapter set, `dt` and duration, `run` shall produce an identical final World and identical metrics, with no wall-clock reads; `run` shall throw a RangeError, before taking any step, for a duration that is not finite, is negative, or is not a multiple of `dt` (within 1e-9 steps), and `run(0)` shall take no step.
- [x] **KERN-007** [all]: When `advance(realSeconds)` is called, the kernel shall throw a RangeError, changing nothing, unless `realSeconds` is finite and at least 0 (so `advance(0)` takes no step and returns 0); otherwise it shall add `realSeconds × world.clock.scale` to a balance of owed world seconds, run as many whole steps as the balance covers up to a per-call cap, keep the sub-step remainder, drop whole steps beyond the cap, and return the number of steps taken.
- [x] **KERN-008** [all]: When `setClock(mode, scale)` is called, the kernel shall throw a RangeError, leaving `world.clock` unchanged, for `realtime` with a scale other than 1 or any scale that is not finite and above 0, and otherwise update `world.clock` for the next `advance` without changing `world.t` or the owed balance.
- [x] **KERN-009** [all]: Running 30 simulated days at the default `dt` with 15 trivial adapters and checked mode on shall take under 1 s of kernel overhead on a laptop in Node; the harness may switch checked mode off if this is missed, tests and the live app keep it on.
- [x] **KERN-010** [all]: Given the same seed and stream name, `rng` shall return the same sequence on every call and every runtime.
- [x] **KERN-011** [all]: Given a different stream name or a different seed, `rng` shall return an independent sequence, so draws from one stream never change another's.
- [x] **KERN-012** [all]: Every value `rng` returns shall be in [0, 1) with a mean near 0.5 over many draws.
