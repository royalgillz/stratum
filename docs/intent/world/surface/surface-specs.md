# Surface and return model specs

Prefix `WORLD-SURFACE`. Design: `surface-design.md`. The problems served are in brackets. Gases are `co`, `o3`, `so2`, in that order; concentrations are ppm. `r` is a required protection factor.

- [x] **WORLD-SURFACE-001** [13]: `surfaceAt(events, t)` shall return the `surface` event with the largest `atH` such that `atH × 3600 ≤ t` (the later in script order on a tie), or null when there is none, ignoring events of other types.
- [x] **WORLD-SURFACE-002** [13]: `crewRead(event, t, rng)` shall return, for crews `c1` to `c<crews>` in order and for each gas in order, one reading `{ crew, gas, ppm, t }` with exactly one draw, `ppm = truth × k × (1 + CREW_NOISE × (2u − 1))`, where `k` is `bias` for crews `c1` to `c<falsified>` and 1 otherwise.
- [x] **WORLD-SURFACE-003** [13, 14]: `required(conc)` shall return the largest concentration over `REL` among the three gases, raised to at least `APF_SEALED` when any gas is at or above its `IDLH` or carbon monoxide is above its `REL`.
- [x] **WORLD-SURFACE-004** [13]: `bandOf(conc)` shall return `open` when `required(conc) ≤ 1`, otherwise `mask` when it is at most 50, `suit` when at most 1,000, `sealed` when at most 10,000, and `closed` above.
- [x] **WORLD-SURFACE-005** [14]: `optionFor(r)` shall return the first entry of `OPTIONS` (factors 1, 10, 50, 1,000, 10,000 in rising order) whose factor is at least `r`, or null when `r` is above 10,000.
- [x] **WORLD-SURFACE-006** [14]: `trialPlan(startR, trueR, staged)` shall run options from `optionFor(startR)` upward, each through `STAGES` in order when `staged` and through the 720 h stage alone otherwise, count a stage as breached exactly when `trueR` is above the option's factor, add `TRIAL_N` person-hours for a breached stage and `TRIAL_N` times its hours for a held one, move to the next option after a breach, and return `{ verified, exposureH, breaches, stages }`, with `stages` the stages run, in order, each `{ factor, hours, breached }` (hours 1 for a breached stage), and `verified` the factor of the first option whose 720 h stage holds, or 0 when none does; with no option for `startR` it shall return `{ verified: 0, exposureH: 0, breaches: 0, stages: [] }`.
- [x] **WORLD-SURFACE-007** [15]: `returnPerDay(shafts)` shall return `min(SHAFT_PPH × SHAFT_H × shafts, RECEPTION_PD)` people per day.
- [x] **WORLD-SURFACE-008** [13, 14, 15]: The surface functions shall throw a RangeError for a non-finite `t`, a negative or non-finite concentration, factor, `bias` or shaft count, a `surface` event whose `crews` is not an integer of at least 1 or whose `falsified` is not an integer from 0 to `crews`, or a non-finite `atH`.
