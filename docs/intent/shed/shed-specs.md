# Shed Ledger specs

Prefix `SHED`. Design: `shed-design.md`. The problems served are in brackets. An event's minute and a packet's minute are Unix minutes; `nowMs` is Unix milliseconds from the caller.

- [x] **SHED-001** [1]: When `tier(nowMs, tier)` is given AMBER or RED and the previous call's tier was GREEN, the Shed Ledger shall open an AMBER event at minute `floor(nowMs / 60000)`, and when it is given RED and the previous call's tier was GREEN or AMBER, it shall open a RED event at that minute, treating the tier before the first call as GREEN; the previous call's tier is updated even when SHED-002 suppresses the event.
- [x] **SHED-002** [1]: The Shed Ledger shall open no event when `tier` repeats or lowers the previous tier, and shall not open an event of a tier whose previous event of the same tier started fewer than 10 minutes earlier (event minute minus previous event minute below 10).
- [x] **SHED-003** [1]: If `tier` is called with a `nowMs` that is not finite or is earlier than the previous call's `nowMs`, or with a tier other than GREEN, AMBER or RED, then the Shed Ledger shall throw RangeError and leave its tier, time and events unchanged.
- [x] **SHED-004** [1, 2]: When `report(packet)` is called, the Shed Ledger shall store the packet as cut evidence and return true only if its type is OK (0) or REPORT (2), it is not marked `duplicate`, payload flags bit 0 is 0 (power off), its minute is an integer and payload level is an integer from 1 to 6, and otherwise shall store nothing and return false.
- [x] **SHED-005** [1, 2]: The Shed Ledger shall count a level as cut during an event when at least 3 distinct senders, a sender being the pair (key set id, member byte), have stored reports of that level with a packet minute `m` where event minute ≤ `m` < event minute + 10, counting each sender once however many reports it sent.
- [x] **SHED-006** [1, 2]: `odds(level, tier, nowMs)` for tier AMBER or RED shall return `{ p, cuts, events, label }`, where `events` is the number of events of that tier with `(event minute + 10) × 60000 ≤ nowMs`, `cuts` is how many of those count the level as cut (SHED-005), `p = (cuts + 1) / (events + 2)`, and `label` is the label given at creation.
- [x] **SHED-007** [1, 2]: While no event of the requested tier has a window ended by `nowMs`, `odds` shall return `p` exactly 0.5, `cuts` 0 and `events` 0, the result callers display as "no data yet".
- [x] **SHED-008** [1, 2]: If `odds` is called with a level that is not an integer from 1 to 6, a tier other than AMBER or RED, or a `nowMs` that is not finite, then it shall throw RangeError.
- [x] **SHED-009** [1, 2]: For the same `tier` calls and the same set of reports, `odds` shall return the same result whatever order the reports arrive in, before, between or after the `tier` calls, including reports that arrive after their event's window has ended.
- [x] **SHED-010** [1, 2]: `createShedLedger({ label })` shall throw RangeError for a label other than LIVE, REPLAY or SIMULATED, and the Shed Ledger shall read no clock and use no randomness, taking every time from its caller.
