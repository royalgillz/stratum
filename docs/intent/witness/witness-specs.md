# Witness specs

Prefix `WIT`. Design: `witness-design.md`. The problems served are in brackets. A median of an even count is the upper of the two middle values. "Latest" means last appended or supplied, never largest `t`.

- [x] **WIT-001** [4]: The witness shall run one change detector per `(kind, where)` stream over measured observations only, judging each reading against the baseline held before it (the median of the last 48 admitted readings, with scale `max(1.4826 × MAD, 1% of |median|, 1e-9)`), and shall admit every reading, mark none exceeding and open no event until 24 readings are admitted.
- [x] **WIT-002** [4]: When a measured reading has `|x − median| / scale ≥ 4`, the detector shall mark it exceeding and shall not admit it to the baseline.
- [x] **WIT-003** [4]: When a stream has no open event and its latest reading is exceeding and completes 3 exceeding readings among its last 5 readings (admitted or not), the detector shall open an event `{ kind, where, tStart, tDetect, direction, peakZ }`, with `tStart` the time of the earliest exceeding reading among those 5, `tDetect` the time of the latest, `direction` +1 or −1 by the sign of the latest reading's residual, and `peakZ` the largest `|z|` among its exceeding readings so far, raised by later exceeding readings while the event is open.
- [x] **WIT-004** [4]: While an event is open, the detector shall admit no reading to that stream's baseline and open no second event, and after 5 consecutive non-exceeding readings it shall set the event's `tEnd` to the time of the fifth, clear the stream's last-5 window, and resume admitting readings.
- [x] **WIT-005** [1, 4, 9, 13]: When `observe` is called, the witness shall append one entry stamped with the injected clock's `now()` to `ledger.official` if `source` equals `official` or starts with `official:`, otherwise to `ledger.measured`, before returning, and shall throw RangeError and append nothing if `now()` or `value` is not finite or a string exceeds 65535 UTF-8 bytes.
- [x] **WIT-006** [1, 4, 9, 13]: The witness shall set each entry's `hash` to the lowercase hex of `SHA-256(prev ‖ t ‖ value ‖ lp(kind) ‖ lp(where) ‖ lp(source))`, with `t` and `value` as big-endian float64 (`-0` as `0`), `lp(s)` a 2-byte big-endian length then the UTF-8 bytes, and `prev` the previous entry's raw hash bytes or, for a chain's first entry, the SHA-256 of the UTF-8 string `STRATUM-ledger-v1:measured` or `STRATUM-ledger-v1:official`.
- [x] **WIT-007** [1, 4, 9, 13]: The witness shall compute SHA-256 synchronously in pure TypeScript with output equal to the FIPS 180-4 test vectors and to `crypto.subtle.digest` for the same input, so that every entry is complete when `observe` returns.
- [x] **WIT-008** [1, 4, 9, 13]: The witness shall never modify or remove an appended entry, and `verifyChain(entries, chain)` shall return `{ ok: true }` when every hash recomputes from the genesis, otherwise `{ ok: false, index }` with the first entry that does not.
- [x] **WIT-009** [4, 13]: `gap(kind)` shall return the mean, over each `where` holding both a measured and an official entry of that kind, of the latest measured value minus the latest official value, and NaN when no `where` holds both.
- [x] **WIT-010** [13]: `digest()` shall return the first 16 bytes of the measured chain head as 32 lowercase hex characters, where the head is the last measured entry's hash or the measured genesis hash if the chain is empty, and `head(chain)` shall return the full head of either chain.
- [x] **WIT-011** [9]: `chapman(n1, n2, m)` shall, for non-negative integers with `m ≤ min(n1, n2)`, return `{ n, lo, hi }` with `n = (n1+1)(n2+1)/(m+1) − 1`, `n ± 1.96·√var` for `hi` and `lo` (`lo` raised to at least `n1 + n2 − m`), `var = (n1+1)(n2+1)(n1−m)(n2−m) / ((m+1)²(m+2))`, and shall throw RangeError for any other input.
- [x] **WIT-012** [13]: `quorum(readings, gas)` shall take each crew's latest reading of that gas (largest `t`, later in the array on a tie), compute the median `ppm`, and, when at least 3 crews have `|ppm − median| ≤ 25% × |median|`, return `{ value: median, agreeing: that count }`, otherwise return null.
