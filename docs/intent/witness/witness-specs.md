# Witness specs

Prefix `WIT`. Design: `witness-design.md`. The problems served are in brackets.

- [ ] **WIT-001** [4]: The witness shall run one change detector per `(kind, where)` stream over measured observations only, keep a baseline of the last 48 admitted readings with scale `max(1.4826 × MAD, 1% of |median|, 1e-9)`, and report no exceedance and no event until 24 readings are admitted.
- [ ] **WIT-002** [4]: When a measured reading has `|x − median| / scale ≥ 4`, the detector shall mark it exceeding and shall not admit it to the baseline.
- [ ] **WIT-003** [4]: When 3 of a stream's last 5 readings are exceeding, the detector shall open an event `{ kind, where, tStart, tDetect, direction, peakZ }`, with `tStart` the time of the first exceeding reading in that run and `tDetect` the time of the reading completing 3 of 5.
- [ ] **WIT-004** [4]: While an event is open, the detector shall admit no reading to that stream's baseline, and after 5 consecutive non-exceeding readings it shall set `tEnd`, close the event and resume admission.
- [ ] **WIT-005** [1, 4, 9, 13]: When `observe` is called, the witness shall append one entry stamped with the injected clock's `now()` to `ledger.official` if `source` equals `official` or starts with `official:`, otherwise to `ledger.measured`, before returning, and shall throw RangeError and append nothing if `now()` or `value` is not finite or a string exceeds 65535 UTF-8 bytes.
- [ ] **WIT-006** [1, 4, 9, 13]: The witness shall set each entry's `hash` to the lowercase hex of `SHA-256(prev ‖ t ‖ value ‖ lp(kind) ‖ lp(where) ‖ lp(source))`, with `t` and `value` as big-endian float64 (`-0` as `0`), `lp(s)` a 2-byte big-endian length then the UTF-8 bytes, and `prev` the previous entry's raw hash bytes or, for a chain's first entry, the SHA-256 of the UTF-8 string `STRATUM-ledger-v1:measured` or `STRATUM-ledger-v1:official`.
- [ ] **WIT-007** [1, 4, 9, 13]: The witness shall compute SHA-256 synchronously in pure TypeScript with output equal to the FIPS 180-4 test vectors and to `crypto.subtle.digest` for the same input, so that every entry is complete when `observe` returns.
- [ ] **WIT-008** [1, 4, 9, 13]: The witness shall never modify or remove an appended entry, and `verifyChain(entries, chain)` shall return `{ ok: true }` when every hash recomputes from the genesis, otherwise `{ ok: false, index }` with the first entry that does not.
- [ ] **WIT-009** [4, 13]: `gap(kind)` shall return the mean, over each `where` holding both a measured and an official entry of that kind, of the latest measured value minus the latest official value, and NaN when no `where` holds both.
- [ ] **WIT-010** [13]: `digest()` shall return the first 16 bytes of the measured chain head as 32 lowercase hex characters, where the head is the last measured entry's hash or the measured genesis hash if the chain is empty, and `head(chain)` shall return the full head of either chain.
- [ ] **WIT-011** [9]: `chapman(n1, n2, m)` shall return `N = (n1+1)(n2+1)/(m+1) − 1` with a 95% interval `N ± 1.96·√var`, `var = (n1+1)(n2+1)(n1−m)(n2−m) / ((m+1)²(m+2))`, the lower end clamped to at least `n1 + n2 − m`, and shall throw RangeError for a negative input or `m` above `n1` or `n2`.
- [ ] **WIT-012** [13]: `quorum(readings)` for one gas shall take each crew's latest reading, compute their median, and return that median and the count of crews within 25% of it when at least 3 distinct crews are within 25%, otherwise return no quorum and no value; the witness shall use no randomness, browser API or clock other than the injected one, so the same observations and clock always give the same hashes and events.
